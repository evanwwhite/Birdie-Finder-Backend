# Source register and public-use gate

Reviewed 2026-10-03 against the checked-in clients and the provider pages linked below. This is an evidence register, not permission inferred from a successful API call. **No third-party catalog feed or legacy CSV is approved for public import or publication yet.** The synthetic fixture is approved for internal testing only. Before changing a source to `public approved`, record the product scope, the exact fields, a permission or license basis, attribution, refresh budget, and a reviewer/date in the approval ledger below.

## Approval ledger

No third-party source is approved for **public import/promotion** as of 2026-10-03. `internal_synthetic` is accepted only for development fixtures. For each future decision, add a row with source ID, exact field set, use (display/import/cache/redistribute), commercial scope, geography, license or written permission link, attribution text, refresh budget, reviewer and approval date. A provider's API response, an open-source code license, and a data license are separate evidence.

The C2 importer must refuse sources without an approval row and must keep source assertions, competing values, and review outcomes in `internal` staging. The existing CSV comparison report is an audit of repository contents; it grants no right to publish either file.
